SCRAP // TITAN — Windows 개발 플레이 빌드 v0.3.1 (v012)

실행 방법
1. ZIP의 모든 파일을 원하는 폴더에 압축 해제합니다.
2. ScrapTitan-v0.3.1-Windows-x64 폴더를 엽니다.
3. ScrapTitan-Prototype.exe를 더블클릭합니다.
Unity Editor와 별도 게임 설치는 필요하지 않습니다.
EXE, UnityPlayer.dll, MonoBleedingEdge, D3D12, *_Data 폴더를 함께 유지하세요.
ZIP 안에서 EXE만 직접 실행하거나 EXE만 다른 폴더로 옮기지 마세요.
Windows x64용입니다. 현재 PC에서 검증했으며 다양한 PC의 최소 사양은 아직 측정하지 않았습니다.

조작
- WASD / 방향키 / 화면 왼쪽 패드 드래그: 이동
- Space / 화면 오른쪽 고철 압축포: 자동 타기팅 궁극기
- 마우스 클릭: 시작 무장, 성장 카드, 부품과 장착 슬롯 선택
- Escape / 화면 오른쪽 위 일시정지: 전투 정지
- 일반 공격, 조준, 근처 아이템 획득: 자동
- 창 닫기 / Alt+F4: 종료

모드와 저장
- 처음에는 짧은 12웨이브 출격을 권합니다(약 3~5분).
- 정규 출격은 100웨이브, 카드 선택과 정지를 제외한 약 25~30분입니다.
- 최종 보스를 처치하면 귀환 연출, 빌드 결과, 로비로 연결됩니다.
- 사망하면 패배 결과에서 다시 시작할 수 있습니다.
- 저장이 있으면 로비의 체크포인트 이어하기를 사용할 수 있습니다.
- 저장은 사용자별 로컬 앱 데이터에 기록되며 ZIP에는 개인 저장이 포함되지 않습니다.

검증 상태
실제 Unity 정규 전투 100웨이브 27분 10초 승리, 짧은 전투, 카드 정지,
부품 교체와 진화, 궁극기, 저장 복구, 승패와 재시작을 검증했습니다.
장시간 Unity 검증은 명시적인 자동 조작을 사용했습니다.
v012 Windows Player에서는 보스전 저장 이어하기와 부품 정비, 승리를 직접 확인했습니다.
이번 ZIP은 그 빌드의 실행 파일 전체와 압축 해제본을 SHA256으로 대조했습니다.
이번 포장 작업에서 새 Windows 실행이나 다른 PC 테스트를 했다는 의미는 아닙니다.
실기기 Android 성능, 물리 멀티터치, 최종 아트와 난이도 평가는 아직 남아 있습니다.
