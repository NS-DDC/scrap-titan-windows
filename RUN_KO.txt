SCRAP // TITAN — Windows v0.5.0 (v015)

실행
ZIP 전체를 압축 해제하고 ScrapTitan-Prototype.exe를 더블클릭하세요.
EXE 옆의 DLL, MonoBleedingEdge, 데이터 폴더를 함께 유지하세요. Unity Editor는 필요하지 않습니다.

먼저 볼 내용
로비에서 '크러셔 · 현장 테스트'를 선택하고 시작 무장을 누르세요.
스파크 드레이크와 부품 운반체 → 성장 → 크러셔 → 전용 카드 보상 → 테스트 결과로 이어집니다.
이 테스트 결과는 100웨이브 전체 게임의 클리어가 아닙니다.
기존 '시제품 · 12웨이브'와 '정규 · 100웨이브'도 선택할 수 있습니다.
정규 출격은 25보스를 처치하고 보상을 고르면 26웨이브로 진행합니다.
100웨이브 최종 보스 처치 뒤에만 귀환합니다.

조작
WASD / 방향키 / 왼쪽 패드 드래그: 이동
Space / 오른쪽 고철 압축포: 원터치 자동 타기팅 궁극기
마우스 클릭: 카드와 부품 장착 슬롯 선택
Escape / 일시정지 버튼: 전투 정지
일반 공격·조준·근처 아이템 획득은 자동입니다.

부품과 성장
운반체가 싣고 온 카트리지·로터·탄두에 대응하는 무장을 장착하거나 강화하세요.
같은 무장 Lv3 + 대응 모듈로 진화합니다. 세 무장은 서로 다른 진화 장식을 가집니다.
크러셔 보상은 3장 중 1장과 보유 무장의 호환 부품을 함께 줍니다.
'파쇄 공명'은 자동 공격 6회마다 추가 범위 충격을 만듭니다.
이전 v014 저장은 원래 전투 규칙을 유지하며 이어집니다. 새 보스 확장은 새 출격에서 적용됩니다.

보관과 설정
체크포인트는 개인 저장 경로에 자동 저장됩니다. 이어하기는 정지 상태에서 재개합니다.
로비/일시정지의 '소리 · 화면 설정'에서 음량과 화면 흔들림을 조절할 수 있습니다.
개인 저장과 개발용 강제 진행 입력은 이 ZIP에 포함하지 않습니다.

이번 전달 범위와 남은 제작
ZIP 기획서의 첫 증분입니다. 25 크러셔·일반 드레이크·전용 보상·종류별 부품을 추가했습니다.
50 이그니스, 유니크 드레이크, 75 바스티온, 100 오메가, 플라즈마 빔·외부 지원·궁극기 변형,
나머지 카드와 진화, 보스 4종 시간표는 후속 제작 목록에 있습니다.
현재 최종 보스는 기존 폐기장 감독기입니다. 오메가가 완성됐다고 표시하지 않습니다.
Android 실제 성능·동시 손가락 터치·OS 중단 복구는 기기 연결 후 확인합니다.
다른 Windows PC 호환성과 사람의 최종 아트·난이도·조작감 평가도 남아 있습니다.
