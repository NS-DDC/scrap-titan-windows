SCRAP // TITAN — Windows v0.4.0 (v014)

실행
ZIP 전체를 압축 해제한 뒤 ScrapTitan-Prototype.exe를 더블클릭하세요.
Unity Editor 설치는 필요하지 않습니다. EXE와 같은 폴더의 데이터/DLL을 함께 유지하세요.
ZIP 안에서 EXE만 직접 실행하지 마세요. Windows x64 개발 플레이 빌드입니다.

조작
WASD / 방향키 / 왼쪽 패드 드래그: 이동
Space / 오른쪽 고철 압축포: 자동 타기팅 궁극기
마우스 클릭: 시작 무장·성장 카드·부품/장착 슬롯 선택
Escape / 일시정지 버튼: 전투 정지
공격·조준·근처 아이템 획득은 자동입니다.

소리와 화면
로비 또는 일시정지의 '소리 · 화면 설정'을 여세요.
전체 음량·배경 음악·효과음을 따로 조절할 수 있습니다.
'효과음 미리듣기'로 현재 음량을 들어볼 수 있습니다.
가벼운 화면 흔들림을 끌 수 있습니다. '저장 · 돌아가기'로 설정을 보관합니다.
카드·부품 선택/일시정지 중에는 전투 효과음이 멈추고 음악이 작아집니다.
앱이 포커스를 잃으면 전투가 정지하고 소리가 멈춥니다.

플레이
로비에서 짧은 12웨이브(약 3~5분) 또는 정규 100웨이브(전투 약 25~30분)를 선택하세요.
레벨업 카드와 적의 부품으로 3종 무장을 강화·교체·진화시킬 수 있습니다.
최종 보스 처치 → 귀환·빌드 결과 → 로비. 사망 시 결과에서 다시 시작할 수 있습니다.
저장이 있으면 체크포인트 이어하기가 표시됩니다. 개인 저장은 이 ZIP에 포함되지 않습니다.

이번 버전
원래 A 메카·가로 화면 유지. 16종 모델의 전용 UV 베이크 재질, 금속·음영·발광·노멀 맵.
3곡의 산업 기계 분위기 BGM, 16종 효과음, 음량 설정.
메카 하체 동작·무장 반동, 연사기 섬광·톱날 불꽃·곡사포 연기·압축포 광선 보완.

남은 품질 확인
실제 Android 성능·동시 터치·OS 중단 복구는 기기 연결 후 진행합니다.
다른 Windows PC 호환성과 사람의 최종 아트·청취·조작감·난이도 평가는 별도로 남아 있습니다.
측정되지 않은 PC 최소 사양이나 모든 기기의 실행을 보장하는 배포본은 아닙니다.
